# Support

ModuleOS is a community-maintained open-source project. Support is provided on a
best-effort basis and does not include a service-level agreement.

## Where to ask

- Use [GitHub Discussions](https://github.com/mevlutkural/moduleos/discussions)
  for usage questions, design conversations, and general help.
- Use [GitHub Issues](https://github.com/mevlutkural/moduleos/issues) for
  reproducible defects and scoped feature proposals.
- Use [private vulnerability reporting](https://github.com/mevlutkural/moduleos/security/advisories/new)
  for suspected security issues.
- Follow the confidential reporting process in the
  [Code of Conduct](CODE_OF_CONDUCT.md) for conduct incidents.

## Useful information

When asking for help, include the relevant ModuleOS version or commit, operating
system, runtime version, configuration with secrets removed, expected behavior,
actual behavior, and the smallest reproducible example you can provide.

Never publish credentials, access tokens, private keys, customer data, or
unredacted production logs.

## Version support

Only versions identified in the [Security Policy](SECURITY.md) receive security
support. Documentation and examples normally target the latest supported release.
